# R-project_Tocilizumab
This is a cost-utility model built to update the HTA of Tocilizumab produced by Roche. 

## 1. Overview of Model Structure

The HTA for tocilizumab in GCA used a semi-Markov model with seven health states:
- On remission and on steroid
- On remission and off steroid
- On relapse/flare
- On remission and on maintenance steroids (escape)
- GCA-related complications
- Steroid-related AEs
- Dead
